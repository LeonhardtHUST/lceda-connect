## 工程树右键菜单矩阵（实测 4.1.78）

同一棵树上，右键菜单随节点类型变化。实测 6 个位置：

| 右键位置 | 菜单条目 |
|---|---|
| example-account | 刷新、全部展开、全部折叠、新建工程...、新建文件夹... |
| <个人工程-01> | 刷新、排序、打开工程、在新窗口打开...、移动...、在工作区打开、工程管理、备份管理 |
| example-team | 刷新、全部展开、全部折叠、新建工程...、新建文件夹...、团队管理 |
| 我参与的 | 刷新 |
| 官方示例工程 | 刷新、全部展开、全部折叠、新建工程...、新建文件夹...、团队管理 |
| (空白区) | 刷新、排序、全部展开、全部折叠、新建工程... |

### 归纳

| 节点类型 | 菜单特征 |
|---|---|
| 账号 / 团队节点（example-account、example-team、官方示例工程） | 刷新、全部展开、全部折叠、新建工程...、新建文件夹...、团队管理 |
| 工程节点（<个人工程-01>） | 刷新、排序、打开工程、在新窗口打开...、移动...、在工作区打开、工程管理、备份管理 |
| 只读分组（我参与的） | 只有刷新 |
| 空白区 | 刷新、排序、全部展开、全部折叠、新建工程... |

### 操作要点

- 右键用 `mousePressed/mouseReleased` + `button: "right"`、`buttons: 2`，单发即可弹出，不需要 clickCount。
- 弹出后 `Esc` 可关；关之前先抓条目，再 Esc，避免菜单叠层。
  注意这条**只适用于工程树面板的菜单**（菜单在页面 DOM 里，由外层壳处理）。
  画布里的右键菜单 `.ctxmenu-ulist` 不吃 Esc，再右键也关不掉，**只能点画布空白关闭**；
  详见 `02-input-and-canvas.md`「工具归零」一节。
- 「新建工程...」「新建文件夹...」「团队管理」「移动...」「备份管理」都会跳出后续界面，属于写操作，需要单独授权。
- 「打开工程」「在工作区打开」是只读视图切换，可用于打开指定项目。

## 设置界面结构 与 快捷键总表

### 对话框形态（实测）

| 项 | 值 |
|---|---|
| 容器 | `div.lc_modal_RVdjQ`，位置 208,103，尺寸 1048×624 |
| 左侧导航 | 可滚动列表，宽 195，行高约 24，含 20+ 分类 |
| 右侧内容 | `lc-table-body_uoDkx`，视口 624×420，内容高 14076，约 612 行 |
| 关闭 | `Esc` 有效，关闭后 `[class*=modal]` 可见节点从 4 个变为 0 |

左侧导航分类（顶层）：系统 / 原理图-符号-仿真 / PCB-封装 / 面板-面板库 / 常用字体 / 图纸 / 属性 / 保存 / 快捷键 / 顶部工具栏

二级分类（系统下）：通用、文件、编辑、视图、放置、设计、布线、布局、工具、导出、设置、帮助；原理图下的二级：通用、主题、显示、网格、线宽、过孔、吸附

### 爬取方法（可复用）

1. 点顶栏 `设置` → 点目标分类（如 `快捷键`），等 1.2 秒让弹层渲染。
2. 用 `elementFromPoint(700,400)` 取命中元素，向上找到 `scrollHeight > clientHeight + 20` 且 `clientWidth > 300` 的祖先，这就是表格滚动容器。
3. 记录 `clientHeight`、`scrollHeight` 和容器 `top`。
4. 循环 `scrollTop = 0, 0.85h, 1.7h, ...`，每帧抓取容器内所有叶子文本的 `(文本, x, 内容y)`。
5. `内容y = scrollTop + (元素的viewportTop - 容器top)`，按 23px 行高分桶，同一桶内按 x 排序就是一行。
6. 去重后得到全表。612 行里 174 行带快捷键，其余是只有功能名的命令。
7. 收尾 `Esc` 关窗，并复核 `[class*=modal]` 已消失。

坑：

- 先用 `z-index` + 面积最大去找弹窗会命中全屏遮罩（rect 0,0），必须加「宽 < 视口 95%」约束。
- 按视口 y 分桶会让不同页的同 y 行互相覆盖，必须换算成内容坐标。
- 表格里「功能 / 快捷键 / 命令」三列，命令列是可直接键入的命令串，比快捷键更可靠。

## 机器可读的菜单目录（2026-11-03）

`references/menu-catalog.json`：由 `scripts/menu_tree.py` 生成，覆盖 设计/布线/布局/放置/工具，
逐条标注 `kind`（`button` / `submenu` / `submenu-unexpanded`）。

判据是结构：条目内存在 `[class*="menu-item-arrow"]` 才是二级菜单。
按文本判断会错——`扇出布线...`、`草图自动布线...` 是按钮，`布线模式`、`布线拐角` 是二级菜单。

重新生成：

```bash
EASYEDA_CDP_TIMEOUT=60 python scripts/menu_tree.py --title <片段> \
  --menus 设计,布线,布局,放置,工具 --depth 1 --out references/menu-catalog.json
```
