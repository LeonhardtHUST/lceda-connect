# 实测结构基线

实测对象：嘉立创EDA专业版 4.1.78.34f5b8d9 / Electron 41.2.1-jlc-sa-win-x64.6 / Chromium 146.0.7680.188，Windows x64，视口 1463×829。

下面的数字用来判断「结构有没有漂」，不是恒定事实。换版本后先用 `scan` 复核，对不上就以新结果为准。

## 页面与 frame

| 项 | 实测值 |
|---|---|
| page 标题 | `嘉立创EDA(专业版) - V4.1.78` |
| page URL | `https://pro.lceda.cn/editor?cll=warn` |
| 主 frame | 与 page 同 URL，约 5000 个元素 |
| 子 frame | 一个 `about:blank`，空壳状态下只有 1 个节点 |

空壳状态的 frame 树只有两层，看不到编辑器 frame。打开设计文件后才会出现带 `entry=` 参数的编辑器 frame，取值以当时探测结果为准。

## 开始页状态（未打开工程）

30 个区域节点，结构大致：

```text
[box] body
  [topbar] 第一行：logo、文件、视图、工具、高级、设置、帮助、API Gateway、搜索、版本、账号
  [toolbar] 第二行：一排图标按钮
  [box] 工作区
    [sidebar] 左侧 255px：24px 图标栏 + 229px 面板
      [sidebar] 工程树滚动区，行高 26，首行是账号名
    [box] 中央 1208px：开始页
      [box] 快速开始面板（功能磁贴）
      [sidebar] 右侧 234px：消息、公众号
```

## 打开工程后的布局差异

双击工程树里的项目条目后，同一份 page 变成编辑器布局：

| 区域 | 开始页状态 | 打开工程后 |
|---|---|---|
| 左侧面板 | 工程树，标题「工作区:」 | 变成面板标签条：图页 / 所有工程 / 工程设计 / 常用库 |
| 中央 | 开始页磁贴 | 标签「开始页」+ 空白画布区 |
| 右侧 | 消息面板 234px | `工程` 面板收成 25px |
| 顶栏第二行 | 8 个控件 | 10 个控件 |
| 节点总数 | 30 | 27，且有多处位移与尺寸变化 |

这正是「布局随条目种类变化」的证据：**必须分状态扫，单张地图一定是错的**。

## 菜单

- **点击标题才展开**，悬停不展开；条目悬停才出子菜单。
- 弹出层特征：`position: absolute`、`z-index` 十万级、容器高度 100—400px，位于顶栏下方。
- `Esc` 可关闭，但键事件要带 `nativeVirtualKeyCode: 27` 且用 `rawKeyDown`；只发 `keyDown` 时实测关不掉。
- 菜单栏位置：y < 45、x < 视口 70% 的指针手型短文本。右侧账号块和窗口控制不是菜单。
- 开始页状态下 `文件` 菜单：新建(N) / 迁移标准版... / 打开工程(O)... Ctrl+O / 导入(I) / 近期工程(R)。`新建` 与 `导入` 有二级子菜单，`近期工程` 子菜单里是最近打开的项目名加账号名。

## 工程树

- 行元素类名形如 `tree-rowline tree-rowline-selected`，高度 26，起点 x=26，宽 229。
- 开始页状态下 26 行，包含账号名、若干工程名、`我参与的`、`官方示例工程`。
- 对项目条目双击会打开工程；对分组条目双击实测无反应（`frames_changed: false`）。
- 右键工程树弹出的菜单含 `新建原理图` / `新建PCB` / `新建面板` / `新建仿真` / `全部展开` / `全部折叠` 等，**这些条目一律不点**。

## 标签页

- 开始页状态有 `开始页` 一个标签；打开工程后多出左侧面板的 `图页` 这类面板标签。
- 标签元素里找不到可点的关闭控件，悬停也不出现。脚本只能报告清单，由用户手关。
- 面板标签和编辑器标签在结构上相似，按名称匹配才可靠。

## 隐私相关

以下位置在实测中带出了账号信息，报告属于本地私密材料：

- 工程树首行的账号名
- 菜单 `近期工程` 子菜单里的「项目名 - 账号名」
- 顶栏右侧的版本与在线状态

脚本会脱敏 URL 查询参数、邮箱、手机号，但界面文字里的账号名与工程名不会被替换。外发前自己确认。
