# 展开规则与回退

探查界面时会短暂改变界面状态。这份文件规定哪些动作可以做、哪些绝对不做、出事怎么退回去。

## 动作分级

| 级别 | 动作 | 是否改变界面 | 授权要求 |
|---|---|---|---|
| A | `scan`、`entries`、`diff`、`render` | 不改变 | 直接执行 |
| B | `menus`：点菜单标题、悬停条目、Esc 收起 | 短暂改变，自动复原 | 告知后执行 |
| C | `open`：双击工程树条目 | 改变，留下标签页 | 逐条确认 |
| D | `close`：关闭标签页 | 改变 | 逐条确认 |
| 禁止 | 点击菜单条目、输入文字、右键菜单项 | 可能改数据 | 永不执行 |

## 菜单展开的三条红线

1. **点标题可以，点条目不行。** 标题只切换下拉层；条目执行命令，其中包含保存、导出、新建工程、下单。
2. **悬停可以到底。** 悬停只让子菜单浮出，不触发命令，所以二级、三级都可以看。
3. **展开后必须验证收起。** 每个菜单处理完发 `Esc`，再探测一次弹出层；仍开着就再点一次标题。两次都关不掉就停止整轮菜单展开，不要把叠了六个菜单的界面留在那里。

## 工程树条目的挑选

- 先 `entries` 枚举，按名称判断种类，**每种只开一个代表**。
- 优先挑官方示例工程，避开用户自己的项目。
- 分组条目先展开再挑叶子，不要对分组双击后宣称「打开了」。
- 打开后核对 `frames_changed`：`false` 说明界面没进编辑器，报告里要写清楚，不能当成功。

## 禁止清单

菜单条目与右键菜单里出现下列字样时一律不点，也不作为展开目标：

```text
新建  删除  移除  清空  重置  导入  导出  上传  下单  保存  另存
关闭工程  关闭全部  回收站  文件源码  版本控制  工程管理
```

任何带 `...` 的条目都假定会开对话框，不点。

## 回退

| 情况 | 处理 |
|---|---|
| 菜单还开着 | 发 `Esc`；无效则再点一次标题 |
| 打开了不该打开的标签页 | 尝试 `close`；找不到关闭控件就列清单交回用户 |
| 出现对话框 | 立即停止，不点对话框里的任何按钮，把界面交回用户 |
| 双击后界面卡在加载 | 等 `--wait` 超时后按现状扫描，并在报告里标注「加载中」 |
| 扫描本身出错 | 只影响输出文件，界面不受影响，重跑即可 |

## 授权话术要点

执行 `open` 前需要说清四件事：

1. 点哪个条目（第几行、叫什么）
2. 预期发生什么（进入哪种编辑器、多出什么标签）
3. 可能影响什么（会加载工程，云工程首次打开会拉数据）
4. 怎么退回去（扫完尝试关闭标签页，关不掉就交回用户）

一句「可以」只对这一次动作有效。下一次打开另一个条目要重新问。
