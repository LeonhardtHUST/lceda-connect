# EDA 后续工作：脱机前置与连接授权边界

## 当前授权

本次只执行步骤 1–2（脱机），随后停止。步骤 3 是第一个需要连接 EDA 的步骤，必须等用户再次明确授权；不能以历史授权、客户端可能已在线或自动续轮代替。

脱机阶段禁止启动/连接 EDA、Bridge、CDP，禁止查询进程/会话或访问本地端点。禁止运行可能自动探桥的全量测试。macOS/Linux 不做实机验证；新增代码仍须保持路径、命令和可选依赖的跨平台设计。

## 连接阶段必须具备的安全条件

- 所有真机步骤串行；不得让真机代理和对话框采集代理同时操纵同一客户端。锁取得失败就停止，不自行绕过。
- 新建运行目录，避免复用旧 session id、windowId 或过期原始结果。记录版本、工程/文档类型与初始标签；用户工程不保存、不改图元。
- `.eprj3` 是可能双向同步的文件夹：先离线复制合法样本至独立运行目录，保留文件哈希清单；不直接用客户端打开上游仓库中的原样本。
- CLI 源码用 UTF-8 文件参数传递，调用参数列表不经过 shell 字符串拼接；启动前做静态语法检查，且不能靠重试未知写操作验证转义。
- 临时 Board/文档/图元使用唯一名称并记录返回 id；异常也进入清理路径。临时标签关闭、对象删除、headless destroy 均须回读确认，不能仅凭调用无异常声明干净。
- 当前授权不包含执行这些安全检查本身：包括 session list、Bridge health、CDP 发现等也必须等待步骤 3 的授权。

## 验收与状态纪律

脱机测试只运行已审查的本仓比较器/解析器测试；排除可选外部 Node 对照，不运行自动探测客户端的套件。默认禁用第三方 pytest 插件和外部 conftest。仅使用本仓夹具及临时合成数据，不安装运行依赖。

`compare_layers.equal` 只能表示所选字段一致；不自动证明层序正确、物理数据完整、单位已换算或客户端行为等价。缺失字段、重复层号、推断顺序必须明确处理，不静默给出完整验收通过。

任务“执行过/报告已交付”与“验收通过”分别记录。连接类任务目前均未获本轮授权；本轮不修改 capability-map 的 verified/partial 状态。正式入库遵循 AGENTS.md 的定向测试、路径门禁、隔离 staging 和本地提交纪律，不推送。
